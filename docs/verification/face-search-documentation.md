## 最优性复查

复查没有停留在“与计划一致”，还修正了以下实现风险：

- 以 EventBridge 官方 IMM 事件代替具有持续 Topic 资源费的 MNS；
- IMM Project 只绑定媒体 1920 前缀和临时参考照前缀，不接触原图、备份、品牌或静态资源；
- 整册删除固定为分页 `BatchDeleteFileMeta` → `DeleteDataset` → 读回确认，避免只删本地状态；
- 明确共享口令和网页声明不能证明参考照权属，并保留个人找图码/后台代查作为风险升级后的重审方向；
- 明确所有被索引人脸都需在授权范围，无法排除旁观者时拒绝整册启用；
- iPhone HEIC/HEIF 仅在浏览器原生解码时本地转 JPEG，不引入云端转换或大型新依赖。

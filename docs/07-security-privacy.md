# 安全、隐私与合规

状态：已批准的实施基线；人脸找图安全控制已本地实现，生产合规未验证
更新日期：2026-09-02

本文件是工程基线，不替代学校或专业人员的法律意见。

## 1. 保护目标

1. 未获授权者不能进入默认相册或后台。
2. 上传者不能写入任意 OSS 路径、覆盖既有对象或获取长期密钥。
3. 获得媒体 URL 的人只能在有限时间内访问对应对象。
4. 照片正文不经过香港应用服务器。
5. 不收集实现直播不需要的观众身份或设备数据；未来人脸找图只在明确目的、单独同意、相册隔离和最短保留下处理必要生物特征。
6. 删除、隐藏、角色和访问策略变化有审计、可重试且不谎报完成。
7. OCR 候选未经人工确认不能进入观众搜索，号码值不能出现在 URL、日志、统计或 SSE。
8. 参考照不经过香港、不长期保存；人脸向量和供应商额外属性不进入 PhotoStream，个人搜索结果不广播给其他观众。

## 2. 信任边界

| 边界 | 信任假设 | 必要控制 |
| --- | --- | --- |
| 观众浏览器 ↔ 香港 API | 完全不可信 | 口令会话、限流、输入校验、短期 URL |
| 内部浏览器 ↔ 香港 API | 账号可能被盗 | RBAC、CSRF、会话吊销、审计、重新认证 |
| 上传浏览器 ↔ OSS | 客户端可篡改请求 | 精确 object key、签名头、大小限制、禁止覆盖、HEAD 验证 |
| 上传浏览器 OCR ↔ 香港 API | 候选可能错误或被伪造 | 服务端规则校验、候选上限、人工确认门禁、号码加密；不接收图片 |
| 观众浏览器 ↔ 临时 OSS（未来） | 参考照和客户端声明不可信 | 单独同意、单图预检、精确短期 PUT、禁止覆盖、HEAD 校验、快速删除 |
| 香港 API ↔ 北京 IMM（未来） | 供应商输出可能错误或包含额外属性 | 每相册 Dataset、允许列表字段映射、高精度阈值、PostgreSQL 权威过滤 |
| EventBridge ↔ 香港 API（未来） | 公网事件可伪造、重放或重复 | 官方证书 URL、RSA 签名、60 秒窗口、账号/地域/项目/任务绑定、幂等 |
| CDN ↔ 私有 OSS | 只信任阿里云授权角色 | 私有回源、最小只读权限、源站信息隐藏 |
| 香港主机 ↔ 数据库 | 主机是核心信任域 | 私网容器网络、数据库不公网暴露、加密备份 |
| 香港主机 ↔ 阿里云控制 API | 长期 RAM 密钥高风险 | 最小权限、环境注入、轮换、禁止根账号密钥 |
| 域名所有者 ↔ CDN | DNS 由朋友控制 | 书面操作清单、配置化域名、证书到期提醒 |

## 3. 主要威胁与缓解

| 威胁 | 缓解措施 |
| --- | --- |
| 相册口令枚举 | 至少 8 位随机口令、指数等待、每日轮换 IP-HMAC 限流、通用错误消息 |
| 后台撞库 | Argon2id、最小 12 位密码、失败限流、会话吊销、首次改密 |
| 越权发布/下载 | 每个服务端操作重新检查角色、相册和下载开关，不信任前端隐藏按钮 |
| 任意 OSS 上传 | 服务端分配 key，预签名绑定方法/路径/头/过期时间，禁止客户端选择 Bucket |
| 对象覆盖 | UUIDv7 不可预测 key、`forbid-overwrite`、数据库唯一约束 |
| 存储滥用 | 每文件与相册配额、上传意图过期、未完成 multipart 清理 |
| CDN 盗链/刷流量 | `/media/` 路径 URL 鉴权、短期签名、对象 key 不可枚举、使用量告警 |
| 号码误关联 | 自动结果只作 `suggested`，人工确认后才生成公共精确搜索索引 |
| 无号码误判 | OCR 无候选/失败/候选全拒绝仍为待复核；只有人工动作可写 `no_number_confirmed` |
| 年级班级错配 | 属性从确认号码确定性派生；年级+班级查询必须在同一号码标签上匹配，冲突映射禁止启用 |
| 号码枚举 | 仅口令相册、POST 精确搜索、无目录/模糊提示、会话与 IP-HMAC 限流 |
| 号码数据库泄漏 | AEAD 密文、相册作用域 HMAC blind index、独立密钥、日志不含号码 |
| 人脸错误关联 | 高精度阈值、授权评测零错误人物关联门禁、只称“可能包含”、不返回相似度 |
| 人脸枚举/跟踪 | 仅口令相册和当前会话私有结果、同相册、严格限流、无人物目录/跨相册搜索 |
| 口令持有人提交第三方照片 | 每次显著告知与授权声明、严格限流、无结果分享链接、投诉处置；声明不是身份核验，剩余风险由学校明确接受 |
| 未授权旁观者进入索引 | 启用前核验整册人脸授权范围，无法排除时禁用整册或持久排除相关照片 |
| 参考照泄漏 | 去 EXIF、随机临时 key、私有 Bucket、最长 1 小时、1 天生命周期兜底、不经香港 |
| 整册生物特征泄漏 | 不下发人脸向量、不在 PhotoStream 保存向量、每相册 Dataset、最小 RAM、30 天删除 |
| EventBridge 伪造/SSRF | 固定 HTTPS 入口、签名验证、证书 URL allowlist、限制重定向/body、事件幂等 |
| 供应商额外属性扩散 | 允许列表只取必要字段，原始响应不落库/日志/备份/API/UI；影响评估如实记录供应商处理 |
| XSS/媒体嗅探 | 不接受 SVG/HTML，严格 Content-Type，`X-Content-Type-Options: nosniff`，CSP |
| CSRF | SameSite Cookie、CSRF token、Origin/Host 校验 |
| 会话窃取 | 全站 HTTPS、HttpOnly/Secure Cookie、短后台会话、改密/禁用后吊销 |
| 删除不完整 | 持久删除任务、逐对象结果、CDN 刷新、失败重试和审计 |
| 敏感日志泄漏 | 查询串/Cookie/口令/签名脱敏，不存原始 IP 或 UA |

## 4. 后台认证

- 密码使用 Argon2id，参数在实现时依据目标 2C2G 主机做基准测试，目标单次验证约 200–500ms且不造成内存耗尽。
- 密码至少 12 位；禁止常见弱密码和与用户名相同。
- 首个管理员由服务器本地一次性初始化，不提供公开注册接口。
- 管理员重置密码生成一次性临时密码，用户下次登录强制修改，并吊销全部旧会话。
- 后台空闲会话默认 8 小时、绝对上限 7 天；管理员执行永久删除、成员重置等高风险操作时要求近期认证。
- 第一版不保存找回问题，不通过日志或 API 返回临时密码第二次。

## 5. 访客相册访问

- 新相册默认 `password`，下载全部关闭。
- 口令只保存 Argon2id 摘要；成功后签发 HttpOnly 访客会话，不在 localStorage 保存口令。
- 访客会话绑定相册 ID 与 `accessVersion`，默认 12 小时过期。
- 修改口令、切换访问模式或管理员主动撤销时递增 `accessVersion`。
- `public` 只代表无需输入口令；媒体仍使用 CDN URL 鉴权。
- 预览/播放地址默认有效 2 小时，下载地址默认有效 5 分钟。临时 URL 被转发后在过期前仍可能使用，UI 和隐私说明必须如实表达。
- 观众号码搜索只允许 `password` 相册；相册改为 `public` 时搜索自动关闭。
- 号码通过 HTTPS POST 正文提交，不写 URL、历史或 Referrer；每个会话和每日轮换 IP-HMAC 每 10 分钟最多 30 次。
- 人脸找图同样只允许 `password` 相册；每次显示独立告知并取得明确同意，参考照搜索每会话/IP-HMAC 每 10 分钟最多 3 次、每天最多 10 次。
- 获得相册口令不等于获得人物目录：没有跨相册、人名检索、公开结果链接或可转交的搜索任务；搜索 ID 只绑定创建它的访客会话。

## 6. 上传安全

- OSS Bucket 私有，浏览器只能使用预签名 URL；不向客户端签发长期 AK/SK。
- API RAM 用户只允许目标 Bucket 的指定媒体前缀所需操作，不授予 Bucket ACL、策略、删除 Bucket 或跨区域复制权限。
- 签名绑定精确 object key、HTTP 方法、Content-Type、必要 OSS 头和有效期。
- 客户端声明长度必须落入媒体限制；完成后 HEAD 长度不符则拒绝标记完成。
- 上传 object key 不含原文件名、用户输入或可执行扩展名。
- 照片来自受信内部账号，但账号仍可能失陷；接受格式严格限制为经内容验证的 JPEG、PNG 和 WebP 静态图片。
- CORS 只允许确切 `APP_ORIGIN`，不使用 `*` 与凭证组合。
- 本地 OCR 候选接口只接受数字、置信度、模型/规则版本和归一化四边形，不接受裁剪图、Blob、data URL 或媒体代理地址。
- 未来参考照使用独立临时私有 Bucket/前缀和用途受限签名，不复用媒体 object key；只接受去 EXIF JPEG、最大 3 MiB/1920 长边，不保存原文件名、自定义身份 metadata 或公共 URL。

## 7. CDN 与缓存安全

- CDN 通过受限阿里云角色读取私有 OSS；禁止把 Bucket 改为公共读。
- URL 鉴权只应用于 `/media/`，公开哈希静态资源 `/assets/` 不鉴权。
- 鉴权参数在验证后不进入缓存 key，避免同一对象按每个访客重复回源。
- 媒体 object key 不覆盖；边缘缓存可以长时间保存。
- 永久删除先删除源对象，再提交 CDN 刷新；在刷新确认前状态显示“删除处理中”。
- URL 鉴权失败请求仍可能产生少量 CDN/HTTPS 费用，不能把鉴权宣传成费用硬上限。

## 8. 未成年人影像与隐私

学校必须在真实活动上线前确定：

- 拍摄、上传、公开展示和允许下载的授权依据；
- 未成年人及监护人的告知/同意流程；
- 不宜公开学生、活动和地点信息的分类规则；
- 删除、更正、撤回授权与投诉联系人；
- 敏感活动强制口令和禁止下载规则；
- 发生误发或账号泄漏后的通知与处置责任人。

产品默认不做人脸识别、姓名/生物特征身份标签、兴趣画像、广告、评论或公网搜索。ADR-012 只批准一个受限例外：学校完成参与者授权核验和影响评估后，管理员可为单个口令相册开启“参考照 → 可能包含此人的已发布照片”候选搜索。人工确认的数字号码标签仍只服务口令相册精确筛选；照片替代文本不得自动推断人物身份。

人脸找图属于敏感个人信息处理，启用前必须：

- 以显著、清晰语言告知处理者、供应商、目的、方式、必要性、影响、保存期限和权利行使方式；
- 取得活动参与者可追溯的单独同意；不满十四周岁参与者取得父母或其他监护人同意，并制定专门处理规则；
- 在处理前完成个人信息保护影响评估并按适用要求保存记录；目的、方式或供应商实质变化时重新评估；
- 搜索者每次提交参考照前再次同意，并声明为本人或监护人/已获授权；不同意不影响普通相册和号码搜索；
- 明确说明共享口令和声明无法技术验证参考照权属；若学校不能接受该剩余风险，应改用个人找图码或后台代查，而不是暗示当前流程完成实名核验；
- 核验被索引照片中所有可识别人脸均处于授权范围；无法排除未同意旁观者时不得启用整册功能，相关照片先退出索引；
- 沿用页面投诉联系人提供撤回/删除渠道。能够确定相关照片时退出相应索引；无法证明范围完整时删除整册 Dataset；
- 如实说明阿里 IMM 会生成年龄、性别、情绪、吸引力等额外属性，PhotoStream 虽不使用/保存这些字段，供应商侧处理仍纳入告知和评估。

号码牌可能编码年级、班级或学生序号，应按可关联个人的标识符处理，即使活动方称其为临时号码：

- 不导入学生姓名、花名册或号码到个人身份映射；只允许号码到年级/班级类别的确定性位置映射；
- 只有人工确认号码可供口令相册精确搜索，其确定性派生年级/班级才可用于属性筛选；
- OCR 未识别到号码不能自动证明照片“无号码”；无号码结论必须人工确认并可撤销；
- 不提供跨相册搜索、号码目录、自动补全或近似匹配；
- 评测照片和标注保存在 Git 外的受控本地目录，未经批准不上传第三方训练平台；
- 学校隐私说明需明确号码找照片用途、访问范围和删除途径。

## 9. 数据驻留与跨境边界

### 9.1 留在中国内地的数据

- 原始照片；
- 480/960/1920 派生照片；
- 学校 Logo 等媒体资源；
- 前端静态构建资源；
- CDN 缓存副本；
- 从香港加密上传到 OSS 的数据库备份。
- 另行授权后使用的临时参考照、IMM 人脸 Dataset、检测/聚类/相似搜索元数据和 EventBridge 源事件。

### 9.2 香港侧数据

- 内部账号、角色和会话；
- 相册标题、说明、分类与访问设置；
- 不含原文件名的照片对象 key、宽高、大小和状态；
- 号码规则/年级班级映射、号码密文、blind index、候选置信度/框坐标、派生属性和无号码复核结论；
- 随机人脸任务 ID、索引/删除状态、短期媒体结果、最小同意回执和 EventBridge 幂等结果；
- 匿名统计摘要与审计记录。

浏览器直传和直读是强制架构不变量。香港 API 不提供照片/参考照代理、图片优化或缩略图接口，也不保存人脸向量、供应商额外属性、长期聚类或相似度历史。

香港处理内地自然人的账号/相册元数据仍可能涉及个人信息出境。未来人脸匹配结果、任务和媒体关联经 EventBridge/API 进入香港，属于新增敏感信息跨境边界。学校需确认适用的告知、单独同意、个人信息保护影响评估、出境机制及其他义务。系统的数据最小化设计不能替代这一确认。

## 10. 日志与统计

- 生产反向代理日志默认不保存原始客户端 IP、Cookie、Authorization、相册口令或完整查询串。
- 应用日志使用请求 ID、内部用户 ID、相册/媒体随机 ID、动作结果和稳定错误码。
- 号码搜索值、OCR 原文、号码密文、blind index 和解密结果不得进入应用/代理/CDN日志、统计或 SSE。
- 人脸参考照、供应商原始响应、URI、聚类 ID、相似度、人脸框、额外属性和结果集合不得进入应用/代理/EventBridge 调试日志、统计或 SSE；只记录随机任务 ID、阶段、通用错误码和计费计数。
- 限流只保存每日轮换密钥计算出的 IP-HMAC；密钥轮换后不能跨日关联。
- 匿名访客明细最多保留 30 天，之后只保留日聚合。
- 不启用 CDN 实时日志、第三方埋点、浏览器指纹或跨站 Cookie。
- 安全事件需要临时提高日志时，必须明确范围、保存期限和负责人，并避免媒体/秘密进入日志。

## 11. 秘密管理

必须以运行环境秘密注入且不得提交仓库：

- 数据库密码；
- Cookie/CSRF/游标签名密钥；
- OSS RAM AccessKey；
- CDN URL 鉴权主/备密钥；
- 数据库备份加密密钥；
- 首次管理员引导令牌。
- 号码值加密当前/上一版本密钥及对应版本标识；
- 号码 blind-index 搜索当前/上一版本密钥。
- 未来 IMM/临时 OSS/EventBridge 所需的最小 RAM 凭证和允许的账号/地域/Project 标识；供应商凭证不得下发浏览器。

文档和示例只列变量名，不提供真实值。密钥轮换需要支持 CDN 主/备 key 重叠窗口、会话密钥版本、号码 current/previous 双读与后台重加密，以及 RAM key 撤销。具体顺序见[运维、备份与事件响应手册](13-operations-runbook.md)。

## 12. 响应头基线

主站至少配置：逐请求 nonce 严格 CSP、HSTS、`X-Content-Type-Options: nosniff`、合理 Referrer Policy、Permissions Policy 和 frame 限制。脚本只允许同源 nonce/`strict-dynamic`，OCR WebAssembly 使用 `wasm-unsafe-eval`，Worker 只允许同源/Blob；图片只允许同源、Blob/Data 与 `MEDIA_BASE_URL`，上传连接只额外允许精确 `PHOTO_UPLOAD_BASE_URL`，未来参考照只额外允许精确 `FACE_REFERENCE_UPLOAD_BASE_URL`。浏览器不得直连 IMM/EventBridge。`media-src`、object、frame、脚本属性和任意其他第三方源全部拒绝；生产脚本不得依赖 `unsafe-inline`/`unsafe-eval`。

## 13. 删除与事件响应

- 普通纠错先隐藏，立即从新列表和 SSE 中移除。
- 涉及隐私或误发时，管理员执行永久删除，系统删除全部 OSS 变体并刷新 CDN。
- 永久删除照片/相册同步删除号码密文、blind index、派生属性、复核结论和候选框；人脸功能启用时同步建立可重试 IMM 元数据/Dataset 删除任务。相册结束 30 天后清理未确认、已拒绝和未解决号码候选及整册人脸索引。
- 参考照正常完成或失败立即删除，异常最长 1 小时并以 1 天生命周期兜底；短期搜索结果最长 2 小时。失败时先停止返回，不能把本地隐藏表述为云端已删除。
- 删除任务和刷新结果写审计；失败进入可重试队列并在后台醒目标示。
- 疑似账号泄漏时，禁用账号、吊销会话、检查审计、必要时更改相册口令和 CDN 鉴权密钥。
- 数据库备份恢复演练至少在试运行前完成一次，恢复环境不得连接生产 CDN。

## 14. 上线安全门禁

- 完成 RBAC 和越权负向测试；
- 验证 OSS 公共匿名访问被拒绝；
- 验证上传 URL 不能改 key、改方法、覆盖对象或过期重用；
- 验证口令修改使旧会话失效；
- 验证下载开关在 API 层而非仅 UI 层执行；
- 验证香港服务请求/响应正文不含媒体二进制；
- 验证生产日志不含秘密、口令、完整签名 URL 或原始 IP；
- 验证 OCR 图片未离开上传设备、未确认号码不能搜索、数据库无号码明文且搜索输入不进入 URL/日志/SSE；
- 验证 OCR 无候选不会自动添加号码/属性/无号码结论，年级班级从同一确认号码派生且属性过滤不会跨号码拼接；
- 未来启用前验证参与者授权/影响评估门禁、口令/同意/限流、零脸/多脸/低质量、高精度阈值、跨相册隔离、EventBridge 验签/重放、参考照/结果/30 天索引删除和供应商额外属性丢弃；
- 验证数据库、备份、日志、API、SSE 和浏览器存储没有人脸向量、参考照、聚类、相似度、额外属性或个人结果集合；
- 学校确认隐私说明、授权和投诉删除负责人。

# ADR-001：照片处理在上传者浏览器完成

状态：Accepted；由 [ADR-011](011-photo-only-product-boundary.md) 修订
日期：2026-08-26

## Context

平台需要生成照片缩略/浏览图和号码牌 OCR 候选，但用户要求阿里云账单不增加函数计算或 OSS/CDN 图片/OCR 处理等计费项。香港 2C2G 主机也不得拉取杭州照片，否则会引入跨境媒体处理、额外流量和资源竞争。

## Decision

- 照片派生和 EXIF 清理在上传者浏览器本地完成。
- 启用号码识别时，PaddleOCR.js 在上传者浏览器本地生成数字候选，人工确认后才进入搜索。
- 原始/派生媒体从浏览器直接上传杭州 OSS，香港 API 只协调签名和状态。
- 不支持本地处理时明确拒绝或使用规定回退，不调用云端处理。

## Consequences

优点：阿里云费用边界清晰、照片不经过香港、服务端资源小、派生规格固定。代价：上传设备消耗 CPU/GPU/电量，浏览器关闭会中断，OCR 能力依赖设备，受信上传者承担人工确认与部分处理正确性。

## Rejected Alternatives

- 函数计算/OSS/CDN 图片处理：产生独立计费项。
- 香港主机处理：媒体跨境且与 API/数据库争用 2C2G。
- 只存原图、观众直接加载：CDN 流量和页面性能不可接受。

## Revisit When

用户允许独立媒体计算预算；上传设备失败率长期不可接受；或平台迁移到中国内地且获得可控的专用处理资源。

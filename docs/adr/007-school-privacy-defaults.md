# ADR-007：学校相册采用口令、审核与禁下载默认值

状态：Accepted，部分由 ADR-012 修订
日期：2026-08-26

## Context

平台只供学校使用，影像可能包含未成年人。最初的通用照片直播默认可公开分享，但学校场景中的误发、二次传播和肖像/个人信息风险更高。

## Decision

- 新相册默认使用随机至少 8 位口令。
- 默认先审核后发布。
- 普通图和照片原图下载默认全部关闭。
- 号码识别与观众号码搜索默认关闭；启用搜索时强制保持口令访问并只使用人工确认标签。
- 管理员可对已经完成授权判断的单场活动逐项放开。
- 原首版除本地数字号码牌候选外不做人脸识别、公众搜索、评论、画像或第三方统计；不保存号码到姓名映射。
- [ADR-012](012-consent-gated-face-photo-search.md) 后续批准了一个严格受限的例外：只有学校已完成授权核验、管理员逐相册启用、观众再次单独同意的口令相册，才可使用杭州阿里云 IMM 返回“可能包含此人”的照片候选。该例外不允许姓名身份库、公开相册搜索、跨相册搜索或人物目录。

## Consequences

降低误发和非预期传播，符合学校最小公开原则；代价是家长/师生需要输入口令，管理员需承担审核和授权判断。URL 在有效期内仍可转发，口令不是 DRM。

## Rejected Alternatives

- 默认公开可下载：传播方便但不适合未成年人影像默认风险。
- 每位观众实名登录：隐私收集、短信/微信资质和维护复杂度过高。
- 仅靠难猜链接：链接泄漏后没有第二道访问控制。

## Revisit When

学校形成正式的分级活动策略，能明确哪些活动可公开；任何更宽松默认值都需学校书面确认。人脸找图的具体例外、保留和重审条件以 ADR-012 为准。

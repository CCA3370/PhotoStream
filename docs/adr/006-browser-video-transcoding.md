# ADR-006：浏览器本地 H.264/AAC 视频转码

状态：Accepted
日期：2026-08-26

## Context

平台需要上传和播放短视频，但用户禁止云端转码/视频点播计费。任意手机视频可能是 4K、60fps、高码率、HEVC 或 `moov` 在文件尾，直接播放会造成兼容和流量问题。

## Decision

- 输入只接受 MP4/H.264/AAC（或无音轨），最大 5 分钟/500MB。
- 合规 fast-start 文件直接上传；仅封装不合规时本地重封装。
- 高分辨率/帧率/码率 H.264 使用 WebCodecs + Mediabunny 转成最大 1080p/30fps/约 4Mbps，720p 约 2Mbps。
- 只保存优化版；浏览器能力不足或失败时拒绝并给导出参数。
- 不使用 ffmpeg.wasm 软件转码，不使用 HLS 或多码率。

## Consequences

视频兼容和 CDN 流量可控，不新增云费用；代价是上传设备需要前台运行、消耗电量，WebCodecs 能力因设备而异，单码率在极弱网下仍可能缓冲。

## Rejected Alternatives

- 上传任意视频：播放失败与高流量不可控。
- ffmpeg.wasm：500MB 输入的内存、耗时和手机稳定性风险过高。
- 阿里云 VOD/函数计算：新增独立计费项目。
- 同时保存源片：上传与存储可能翻倍以上。

## Revisit When

学校需要长视频、4K 归档、自适应码率，或允许购买受控云端媒体处理预算。

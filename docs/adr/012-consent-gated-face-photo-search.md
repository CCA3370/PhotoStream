# ADR-012：口令相册采用同意门禁的云端人脸候选找图

状态：Accepted
日期：2026-08-31

## Context

ADR-007 和原产品基线明确排除了人脸识别。学校现已确认活动参与者及相应监护人的人脸处理授权记录，并希望观众在受控相册中提交一张参考照片，筛选可能包含同一人物的已发布照片。

该能力处理生物识别信息，且照片可能包含未成年人。现有照片位于杭州私有 OSS，动态 Web/API/PostgreSQL 位于香港；另有一台无备案的境内 4C4G 主机，但不能作为面向浏览器的正式公网入口。通用百度/腾讯/阿里 VIAPI 人脸库主要面向 Person/Face 身份库，单次只返回 Top N，不适合直接表达相册内同一人物的全部照片。阿里云 IMM 原生支持 OSS 图片索引、人脸聚类、聚类查询和相似图片搜索。

## Decision

- 人脸找图默认关闭，只允许 `password` 相册；管理员逐相册启用前必须确认参与者授权记录、未满十四周岁监护人同意、个人信息保护影响评估和投诉联系人均已就绪。
- 学校必须确认被索引照片中出现的人均处于人脸处理授权范围；存在无法排除的旁观者或未同意者时不得启用整册功能，只能先让相关照片退出索引或放弃启用。
- 使用华东 1（杭州）阿里云 IMM。每个相册使用独立 Dataset 和 `Official:FaceManagement` 模板，只索引已发布且 `photo_1920` 已完成的照片；不建立姓名、学号、号码或其他身份映射。
- 观众每次搜索提交一张清晰单人照并再次单独同意，声明为本人或监护人/已获授权。浏览器去除 EXIF、归一化为最多 1920 长边且不超过 3 MiB 的 JPEG，使用精确预签名 URL 直传杭州临时私有 OSS；参考照正文不经过香港。
- 香港 API 先验证参考照恰好一张合格人脸，再用 `SearchImageFigureCluster` 命中聚类并以 `SimpleQuery` 分页取回候选照片；同时用 `CreateFacesSearchingTask` 补查未聚类或少量出现的人脸，结果通过 EventBridge `imm:Task:FacesSearching` 事件送达香港 API。两路结果按高精度阈值过滤、合并、去重，并再次以 PostgreSQL 权威状态限制为当前相册的已发布照片。
- 只向观众表达“可能包含此人的照片”。优先避免错误关联，不承诺找出数学意义上的全部照片；低清、遮挡、侧脸、年龄跨度或只出现极少次数时可能漏检。
- EventBridge 只使用阿里云云服务专用总线与 HTTPS 目标，不引入 MNS、RocketMQ、函数计算或境内公网应用入口。境内 4C4G 主机不属于该链路。
- IMM 固定返回的年龄、性别、情绪、吸引力、眼镜等非业务属性不进入 PhotoStream：适配器仅提取人脸数量/质量、聚类、URI、相似度和任务状态；原始供应商响应不得写日志、数据库、备份、API 或 UI。学校的影响评估需如实记录供应商仍可能执行这些计算。
- PhotoStream 不保存人脸向量、姓名身份标签或长期搜索历史。临时参考照在同步与异步任务完成后立即删除，最长保留 1 小时，并由 1 天 OSS 生命周期兜底；短期结果最长保留 2 小时。最小同意/处理回执不得包含照片、结果、聚类、IP 或 UA。
- 相册结束 30 天后删除整个人脸 Dataset；恢复直播会重新计算期限。相册改为 `public`、管理员关闭功能或授权范围无法维持时，立即停止新搜索并建立可重试删除任务。
- 不新增观众自助撤回中心；公共页面继续展示学校投诉联系人。管理员可让选定照片退出人脸索引而不删除普通相册照片；若不能可靠证明已覆盖某位撤回者的全部索引，删除整个相册 Dataset。
- 编码、云资源开通、真实样本处理和部署均是独立门禁。本 ADR 只批准设计边界，不自动授权后续阶段。

## Consequences

优点：复用杭州 OSS，参考照和被索引照片正文不经过香港；相册 Dataset 隔离、聚类分页和异步补查比把每张脸伪装为“人员”更贴近图库语义；香港 2C2G 只承担小型控制请求与短期结果。

代价：新增 IMM、EventBridge、索引存储、可能的 WebP 转换和跨地域事件流量费用；匹配结果与聚类标识会进入香港处理范围；供应商会生成超出找图用途的固定人脸属性，虽由应用丢弃仍需纳入告知和影响评估；算法只能返回候选，无法保证完全召回或绝对无误配。仅凭共享相册口令和用户声明也不能技术上证明参考照属于本人或已获授权，学校接受该剩余风险并通过告知、限流和投诉流程约束；如风险不可接受，需另行 ADR 改为个人找图码或后台代查。

## Rejected Alternatives

- 百度、腾讯或阿里 VIAPI 通用人员库：需要把每张照片中的每张脸伪装成 Person/Face，并受 Top N 返回上限影响，全量分页和删除语义复杂。
- MNS 接收异步结果：杭州 Topic 有持续资源占用费；EventBridge 官方 IMM 事件源按事件量更适合低频找图。
- 境内 4C4G 自建公网 API：无备案 IP 不能作为正式浏览器服务入口；自建识别还增加模型许可、准确率、更新和安全责任。
- 浏览器下发整册人脸向量：会把整场参与者生物特征复制给不可信访客设备。
- 香港代理参考照或照片：违反媒体正文不经过香港的架构约束。
- 仅隐藏撤回者结果但继续保留云端索引：不能停止后续处理，也不能证明删除完成。

## Revisit When

- 阿里 IMM 不再支持杭州、聚类/搜索接口或 EventBridge 事件；
- 真实授权评测无法达到高精度门禁，或费用/延迟不可接受；
- 学校不能继续维持参与者授权、影响评估、投诉和删除流程；
- 供应商额外属性处理、数据驻留、训练复用或删除承诺发生实质变化；
- 主控制面迁回中国内地，或出现具备明确许可且更小数据面的自建方案。

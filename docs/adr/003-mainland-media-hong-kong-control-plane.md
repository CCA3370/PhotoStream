# ADR-003：杭州媒体数据面与香港控制面分离

状态：Accepted
日期：2026-08-26

## Context

用户没有适合主站的自有备案域名，但已有香港 2C2G Linux 主机；`cdn.cloverta.top` 已备案并绑定到用户的阿里云 CDN，DNS 由朋友控制。产品主要服务中国内地学校用户，并希望图像内容不出境。

## Decision

- 主站、API、PostgreSQL 位于香港。
- 媒体、品牌图片和静态构建资源位于杭州 OSS，通过中国内地 CDN 分发。
- 浏览器直传/直读媒体并执行本地号码 OCR；香港只保存必要对象 key、加密号码标签和非图像元数据。
- 数据库不保存完整 CDN URL，所有域名均配置化。

## Consequences

大流量和媒体内容留在内地，香港主机负载低；动态 HTML/API/SSE 仍跨境，延迟和可用性受跨境链路影响。内部账号、相册标题等元数据在香港处理，仍需数据出境合规判断。境外观众主动访问时媒体会为交付而跨境。

## Rejected Alternatives

- 主站直接用朋友域名备案：不适合作为学校长期主站且运营主体风险高。
- 全部放香港：大陆上传/下载更慢，媒体内容与流量跨境。
- 暂停项目等待备案：不符合先建设小范围学校平台的目标。

## Revisit When

学校取得自有备案域名和中国内地运行资源；香港动态链路成为稳定性瓶颈；或合规评估要求控制面迁回内地。

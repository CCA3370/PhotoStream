# 人脸候选找图

状态：已批准并完成本地代码实现；云端开通、真实样本、设备验收与部署仍未授权/未验证
更新日期：2026-09-02

## 1. 目标与固定边界

人脸找图只用于已获授权的校内活动。观众在已解锁的口令相册中提交一张参考照片，系统返回“可能包含此人的照片”候选。

固定边界如下：

- 默认关闭，只有管理员逐相册启用；公开相册不得启用。
- 只检索同一相册中当前已发布的照片，不跨相册、不提供人物目录。
- 不建立姓名、学号、号码牌或花名册到人脸的映射。
- 每次只接受一张清晰单人参考照；不做实名核身或活体认证。
- 共享相册口令和“本人/已获授权”声明不能技术上证明参考照权属；这是学校明确接受的剩余风险，不得宣传为身份验证。
- 高精度优先，允许漏检，不允许用降低阈值掩盖错误关联。
- PhotoStream 不保存人脸向量；阿里云返回的非必要人脸属性全部丢弃。
- 功能是独立能力阶段；号码 OCR 的本地推理、人工确认和精确搜索合同保持不变。

## 2. 启用前提

管理员启用相册人脸找图前必须同时满足：

1. 相册为 `password`；
2. 学校保存活动参与者可追溯的单独同意记录；不满十四周岁参与者具有监护人同意；
3. 已完成并保存个人信息保护影响评估，覆盖北京 IMM、香港控制面、EventBridge 和删除流程；
4. 相册隐私说明明确处理目的、方式、供应商、保留期限、准确率限制和投诉联系人；
5. 北京 IMM Project、临时私有 OSS、EventBridge 规则和最小 RAM 权限已通过专用测试；
6. 授权评测集达到本文件的高精度门禁；
7. 费用与账单提醒已确认。
8. 学校确认被索引照片中的全部可识别人脸均在授权范围；无法排除未同意旁观者的相册不得启用，相关照片需先持久标记 `excluded`。

缺一项时配置只能保存为未就绪，不能向观众显示入口。相册改为 `public` 时立即关闭搜索、取消未开始任务并建立整册索引删除任务；改回口令后必须重新确认和重建。

## 3. 数据与部署边界

| 位置 | 允许内容 | 禁止内容 |
| --- | --- | --- |
| 观众浏览器 | 当前参考照内存、去 EXIF JPEG、短期结果 | 整册向量、供应商凭证、持久参考照/结果 |
| 北京临时 OSS | 随机 key 的单次参考照，最长 1 小时 | CDN 绑定、公开 ACL、原文件名和身份信息 |
| 北京媒体 OSS | 已有 `photo_1920` | 新增人脸裁剪图或姓名标签 |
| 北京 IMM | 每相册 Dataset、人脸检测/聚类/相似搜索元数据 | 跨相册 Dataset、姓名/学号映射 |
| EventBridge | IMM 指定任务状态和相似候选事件 | 参考照正文、长期事件仓或业务分析 |
| 香港 API/PostgreSQL | 随机任务 ID、索引状态、短期媒体结果、最小同意回执 | 参考照、人脸向量、额外属性、长期相似度/聚类历史 |

EventBridge 到香港的事件和香港到 IMM 的响应构成新的人脸处理与数据出境边界，必须写入影响评估。参考照和相册照片正文仍只在中国内地 OSS/IMM 流动。

## 4. 相册和索引状态

实现使用独立状态，不能复用媒体发布或号码状态：

| 状态 | 含义 |
| --- | --- |
| `disabled` | 未启用或已完成整册删除 |
| `provisioning` | 正在创建/核对 IMM Dataset |
| `indexing` | 存在待索引照片或聚类任务 |
| `ready` | 可接受搜索；最近照片仍可能增量处理中 |
| `degraded` | 部分任务失败，已有安全结果仍可用 |
| `deleting` | 已停止搜索，正在删除云端元数据 |
| `failed` | 无法安全继续，需要管理员重试或整册删除 |

逐媒体索引任务至少保存 `pending/indexing/indexed/deleting/excluded/failed`。状态只保存供应商任务关联和重试信息，不保存人脸框、属性或向量。

## 5. 照片索引流程

1. 管理员启用后，API 为相册建立独立、不可从标题推断的 Dataset，模板固定为 `Official:FaceManagement`。
2. 只有 `PublicationStatus=published` 且 `photo_1920` 已 HEAD 验证的媒体进入持久索引队列；480/960 发布不等待人脸索引。
3. 调用 `IndexFileMeta` 时使用随机媒体 ID 作为 `CustomId`；供应商 URI 不返回观众，也不写普通日志。
4. 一批索引事件完成并静默至少 10 秒后触发增量 `CreateFigureClusteringTask`；同一相册最多每 5 分钟触发一次，避免逐照片聚类。
5. 隐藏照片先由 PostgreSQL 权威过滤，随后异步 `DeleteFileMeta`；恢复时重新索引。永久删除必须把 IMM 元数据删除纳入持久删除任务，部分失败不能标记完成。
6. 管理员可把指定媒体标记为 `excluded`，删除其 IMM 元数据但保留普通相册照片；后续发布/恢复不能自动重建。

索引不阻塞上传、审核或普通相册浏览。观众端需要明确显示“最近照片可能仍在建立找图索引”。

## 6. 参考照与搜索流程

### 6.1 浏览器预处理和直传

观众每次进入人脸找图都显示独立同意对话框，至少说明处理者、供应商、目的、方式、最长保存、可能影响、准确率限制和投诉方式。观众选择“本人”或“监护人/已获授权”后才创建搜索意图。

浏览器解码 JPEG/PNG/WebP；在目标浏览器能够原生解码时也接受 HEIC/HEIF。统一纠正方向、移除全部元数据并编码为最长边不超过 1920、最大 3 MiB 的 JPEG；无法原生解码时提示改选 JPEG/PNG/WebP，不引入云端转换或大型 HEIC 解码包。API 返回随机、不可覆盖、短期预签名 PUT；浏览器直接上传临时私有 OSS。香港 API 只通过 HEAD 校验大小、类型和 ETag，不下载正文。

### 6.2 两路候选合并

1. `DetectImageFaces` 验证恰好一张达到校准尺寸/质量的人脸；零张、多张或低质量都删除对象并返回可操作的中文提示。
2. `SearchImageFigureCluster` 同步匹配一个达到高精度阈值的聚类；命中后以 `SimpleQuery` 按 `Figures.FigureClusterId` 分页获取全部候选。
3. 同时调用 `CreateFacesSearchingTask(MaxResult=100)`；EventBridge 只把 `imm:Task:FacesSearching` 推给固定 HTTPS 入口，用于补回未聚类或少量出现的人脸。
4. 两路结果分别使用固定、版本化阈值过滤，按媒体 ID 去重；供应商相似度不返回浏览器。
5. 每次返回前重新检查访客会话、相册、`faceSearchEnabled`、媒体发布状态和索引排除状态；隐藏、删除、未发布和跨相册媒体绝不返回。
6. 结果按当前相册发布序号倒序显示，不把相似度伪装成确定身份概率。

同步聚类结果可以先显示，异步补查完成后在同一搜索结果中追加；客户端按带退避的短轮询获取私有任务状态，不使用相册 SSE 广播个人搜索结果。

## 7. API 契约

### 7.1 管理端

| 方法与路径 | 权限 | 行为 |
| --- | --- | --- |
| `GET/PUT /api/v1/albums/{id}/face-config` | 管理员 | 查看/修改开关、授权确认、索引状态和保留期限 |
| `POST /api/v1/albums/{id}/face-index/retry` | 管理员 | 重试失败的可恢复任务 |
| `POST /api/v1/albums/{id}/face-index/exclusions` | 管理员 | 让选定照片退出索引但保留普通浏览 |
| `DELETE /api/v1/albums/{id}/face-index` | 管理员 | 关闭功能并建立整册删除任务 |

启用请求必须携带当前告知版本和“参与者授权范围已核验”确认；服务端仍独立检查口令模式、隐私说明和投诉联系人。

### 7.2 观众端

| 方法与路径 | 行为 |
| --- | --- |
| `POST /api/v1/public/albums/{slug}/face-searches` | 创建访客绑定的搜索意图和精确上传签名 |
| `POST /api/v1/public/albums/{slug}/face-searches/{id}/complete` | HEAD 验证并幂等启动搜索 |
| `GET /api/v1/public/albums/{slug}/face-searches/{id}` | 查询私有状态、候选和结果游标 |
| `DELETE /api/v1/public/albums/{slug}/face-searches/{id}` | 取消展示并尽快清理参考照 |

每个访客会话和每日轮换 IP-HMAC 每 10 分钟最多 3 次、每天最多 10 次。搜索 ID 只对创建它的当前访客会话有效。稳定错误至少包含：功能关闭、索引未就绪、参考照格式错误、无人脸、多脸、质量不足、限流、处理中、供应商不可用和清理失败。

### 7.3 EventBridge 入口

`POST /api/v1/integrations/aliyun/eventbridge` 不接受 Cookie 鉴权，必须验证：

- `x-eventbridge-signature-v2`、官方证书 URL 和不超过 60 秒的时间戳；
- 阿里云账号、`cn-beijing`、IMM Project、Dataset、事件类型和已知 TaskId；
- body 大小、JSON 深度、事件 ID 幂等和任务当前状态；
- 证书 URL 精确域名/协议，防止 SSRF；证书短期缓存并限制重定向。

原始事件不得写日志；映射完成后只保存短期媒体 ID 和通用失败码。

## 8. 保留、删除与运营请求

- 参考照：完成或失败后立即删除；任务异常时 1 小时强制删除，Bucket 1 天生命周期兜底。
- 搜索结果：当前访客会话内最长 2 小时，过期后删除；刷新不恢复参考照。
- 同意回执：只保存告知版本、相册随机 ID、声明类型、时间和结果类别；不含图片、聚类、相似度、IP 或 UA。具体法定留存由学校最终确认。
- 相册索引：直播期间保留；每次进入 `ended` 设置 30 天删除时间，恢复 `live` 清除旧期限；`archived` 不延长期限。整册清理先分页 `BatchDeleteFileMeta`，再 `DeleteDataset`，最后读回确认两者均不存在。
- 媒体删除/退出索引：可重试且必须读回供应商状态；失败时本地先阻止返回，不谎报云端已删除。
- 投诉/撤回：沿用相册公开联系人。管理员先暂停相关结果并删除能够确定的媒体索引；无法证明范围完整时删除整册 Dataset。

## 9. 数据最小化与安全

- 供应商适配层以允许列表映射必要字段；年龄、性别、情绪、吸引力、胡须、眼镜等字段即刻丢弃。
- 数据库、备份、日志、统计、SSE、URL、浏览器历史、Cache Storage 和 IndexedDB 不得出现参考照、向量、聚类 ID、相似度或搜索结果集合。
- 不把供应商原始错误、Bucket、Dataset、URI、RAM 信息或 EventBridge payload 返回客户端。
- 不把用户的声明当作身份核验结果，也不在审计中记录人物姓名；口令泄漏或恶意第三方查询属于需由学校流程处置的剩余风险。
- RAM 拆分为媒体索引只读、临时参考照最小读写删除、IMM Dataset 操作和 EventBridge 配置/运行身份；不得使用主账号 AccessKey。
- EventBridge 规则仅匹配指定 IMM Project 的索引、聚类和人脸搜索任务；不启用事件仓、日志投递或通用操作审计转发。
- 临时 OSS 不绑定 CDN，不允许公共读、列举、版本控制、跨区域复制或日志转存。

## 10. 费用边界

新增计费项包括：

- IMM 人脸检测、相似人脸图片、聚类任务、元数据查询与索引存储；
- WebP 被 IMM 转换时可能产生的 OSS 图片处理费用；
- 临时参考照的 OSS PUT/HEAD/GET/DELETE、短期标准存储和生命周期；
- EventBridge 自定义 HTTPS 目标事件与中国内地到香港的少量跨地域流量。

不使用 MNS Topic/Queue、RocketMQ、函数计算、RDS、Tair、日志服务或事件仓。公开价格只能用于估算：按 2026-08-31 文档，5,000 张照片的基础人脸检测约 1 元，每次聚类约 0.05 元，一万次 EventBridge 自定义目标推送约 0.013 元；索引、查询、转换、存储和流量另计。开通前及 PoC 后必须读取实际账单，不能把估算宣传为费用上限。

## 11. 质量与上线门禁

真实启用前使用 Git 外授权评测集，至少覆盖 50 名人物、每人不同光线/角度/表情/遮挡的参考照和相册照，以及不在相册中的负样本。阈值、供应商版本、评测集版本和时间必须固定记录。

上线门禁：

- 评测集中不得出现错误人物关联；合格清晰人脸的召回率单独报告，不通过降低阈值换取召回；
- 零脸、多脸、低质量和非相册人物得到安全、等价的空结果/重试提示；
- 聚类分页与 Top 100 补查合并后无重复、无跨相册、未发布或已排除媒体；
- 参考照、短期结果和 30 天索引清理在正常、超时、重复事件和部分失败下均可验证；
- EventBridge 验签、重放、伪造证书 URL、错误账号/项目/任务和超大 payload 均被拒绝；
- 数据库、备份、日志、浏览器存储和 API 响应扫描无禁止字段；
- 真实微信/Safari、学校流程、阿里云配置、账单和数据出境评估分别记录，缺失项保持 **Unverified**。

详细分层测试见[测试与验收](10-test-and-acceptance.md)，阿里云配置见[阿里云 OSS/CDN 配置](08-aliyun-cdn-oss.md)。

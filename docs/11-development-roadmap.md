## 4. 阶段 1：工程基础

本地实现状态：2026-08-27 已落盘并通过自动化；目标微信/Safari、VoiceOver/NVDA 和目标 2C2G 主机仍待人工/目标环境验收。

### 工作包

1. pnpm monorepo、Node.js 24、Next.js、Fastify、共享 schema、Drizzle/PostgreSQL。
2. 在目标微信 WebView/Safari/Chromium 上完成 Tailwind 浏览器门禁，在 `apps/web` 建立符合 ADR-010 的 `base-nova`/Base UI/Lucide shadcn 配置和语义 Token。
3. 按 `info → search/docs → add --dry-run/--diff → 审查` 流程只生成试验组件，完成 Base UI WebView/辅助技术门禁后建立三个界面壳和 Storybook 状态样例；不在阶段 1 实现完整业务页面。
4. 本地 Docker 开发数据库与迁移；生产部署配置留到阶段 7。
5. 统一配置校验、结构化日志、请求 ID、错误契约。
6. 本地账号、Argon2id、会话、CSRF、RBAC 和首管理员初始化。
7. 单元/契约/数据库集成测试与静态检查。

### 出口条件

- 空库迁移与测试可重复；
- 三角色的允许/拒绝矩阵通过；
- Tailwind 主版本在组件生成前固定；`pnpm dlx shadcn@latest info --json` 读回符合 ADR-010；Base UI 试验组件、设计 Token 和三个界面壳通过状态样例、键盘与自动无障碍检查；
- 仓库无秘密，配置缺失时启动快速失败；
- Docker 构建在目标资源预算内或有外部构建方案。

## 5. 阶段 2：照片纵向闭环

本地实现状态：2026-08-28 已完成照片直传、发布、口令公共相册、游标/SSE、分片、恢复队列和本地容量门禁；真实设备、授权样片和 OSS/CDN 仍待后续明确授权与验收。

按最小真实行为切片，而不是先完成所有后台页面：

1. 管理员创建默认口令相册和一级分类。
2. 上传者选择一张 JPEG，本地生成 480/960/1920。
3. API 创建意图并通过本地 OSS 适配器/测试服务完成预签名 PUT。
4. 480/960 完成后进入审核/自动发布。
5. 公共相册通过口令、游标 API 和 SSE 看到新照片。
6. 1920/原图后台完成并更新灯箱/下载能力。
7. 扩展至批量队列、multipart、IndexedDB 恢复和格式边界。

### 出口条件

- 完整照片 E2E、弱网失败和 API 重启恢复通过；
- 观众端不请求原图，香港 API 不接收媒体正文；
- 5,000 项分页/虚拟化和 500 SSE 本地压力达到预算。

## 6. 阶段 3：审核与运营

- 审核员/上传者协作和相册级发布模式；
- 待审核、已发布、隐藏、不完整和失败筛选；
- 批量发布、隐藏、改分类和逐项结果；
- 三类下载开关与短期 CDN URL；
- 匿名统计、审计、口令更换会话失效；
- 永久删除任务、OSS 删除适配器和 CDN 刷新适配器；
- 学校隐私说明和删除投诉入口。

出口条件是权限负向测试、删除失败恢复和统计最小化测试全部通过。

## 7. 阶段 4：号码牌闭环

1. 实现结构化号码规则：多模式 OR、任意位置约束 AND、多区间、前导零和规则版本。
2. 实现号码到年级/班级的位置映射、冲突校验、映射版本和确认标签属性重算。
3. 新增号码 AEAD 密文、相册作用域 HMAC blind index、状态/来源/框坐标、派生属性、照片级复核结论和密钥版本。
4. 上传页懒加载自托管 PaddleOCR.js Worker、OpenCV、ONNX Runtime 与 PP-OCRv6 tiny 模型。
5. 1920 本地 OCR 与 480/960 上传并行，失败/无候选不阻塞照片发布且不自动判无号码。
6. 上传者确认自己照片的号码或无号码，审核员/管理员确认全部；旧照片只手工补录。
7. 口令相册通过 POST 精确号码搜索及年级/年级+班级筛选，无号码目录、模糊结果或搜索日志。
8. 使用至少 200 张授权照片完成模型/阈值、WebGPU/WASM、无号码负样本、召回率和性能门禁。

### 出口条件

- 未确认/失效标签在任何路径都不可被观众搜索；
- OCR 无候选/失败/全拒绝不会自动添加号码/属性/无号码，只有人工“无号码”可结束无号码复核；
- 确认号码自动派生正确年级/班级，年级+班级查询不会跨照片内不同号码拼接；
- 数据库、备份、URL、日志、统计和 SSE 均无号码明文或搜索值；
- OCR 图片未离开上传设备，模型只从自有 CDN 加载；
- 自动候选达到约定召回/错误候选/性能门槛；未达时保持禁用/实验，手工标签与搜索仍可工作。

## 8. 阶段 5：视频闭环

1. 上传页懒加载 Mediabunny，完成 MP4/H.264/AAC/限制检测。
2. 实现合规文件直接上传与仅 fast-start 重封装。
3. 通过 WebCodecs 完成 1080p/30fps/4Mbps 与 720p/2Mbps 本地转码。
4. 生成两个 WebP 海报；视频 multipart 完成后才发布。
5. 公共混合网格、灯箱、可视自动播放协调器和 Range 播放。
6. 覆盖编码不支持、取消、切后台、磁盘不足和重新导出指引。

视频阶段不得用 ffmpeg.wasm 软件转码作为“兼容性修复”，也不得引入云端转码。

## 9. 阶段 6：安全与性能加固

- 上传签名篡改、会话、CSRF、越权、限流和日志泄漏负向测试；
- PWA 恢复、孤立上传、删除队列和 outbox 故障演练；
- 2C2G 资源压力、5,000 媒体、500 SSE、长列表和媒体质量基准；
- PostgreSQL 加密备份与隔离恢复；
- 内容安全响应、密钥轮换和 CDN 域名迁移演练文档。
- 号码密钥轮换、规则重校验、候选清理、搜索枚举与 OCR 资源供应链负向测试；

任何性能优化必须有同一数据集前后测量，不能通过放宽质量/安全契约换取通过。

## 10. 阶段 7：部署与试运行

1. 用户提供并确认 `deployment-inputs.md` 中全部必需值。
2. 在获得明确授权后配置杭州 OSS、RAM、CDN、CNAME 和证书。
3. 香港主机使用 Docker Compose 部署 Caddy、Web、API 和 PostgreSQL。
4. 只上传一组测试媒体和固定 OCR 模型资源，完成云端冒烟、第三方请求检查和账单检查。
5. 在 iOS/Android 微信、系统浏览器和校园网络人工验收。
6. 创建小范围试运行相册，观察主机资源、上传失败、CDN 命中和费用。
7. 记录实际结果，未通过项修复后再扩大使用。

部署、DNS、云端资源、提交、推送和发布都需要各自明确授权；编码授权不自动包含这些外部操作。

## 11. 主要风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 香港 2C2G 内存不足 | 构建/运行 OOM | 媒体不进服务端、生产使用独立构建产物、设置进程预算与压力门禁 |
| 手机本地照片批处理 OOM | 上传失败 | 单 Worker 单图、及时释放、限制 100MP |
| 通用 OCR 召回不足 | 号码候选帮助有限 | 200+ 授权样本门禁、结构化规则、手工补录；不自动入索引 |
| OCR 无候选被误当无号码 | 漏掉真实学生照片 | 独立人工复核结论；无候选仍待复核，提供“手工添加/无号码”双动作 |
| 年级班级映射冲突 | 属性筛选错误或跨学生错配 | 冲突配置拒绝、同一号码标签匹配、映射版本持久重算 |
| OCR 模型/运行时过大或慢 | 上传设备耗流量/电量 | 懒加载、自托管长缓存、≤35MB预算、单并发与 WebGPU/WASM 基准 |
| 号码关联未成年人 | 隐私/枚举风险 | 口令相册、人工确认、密文+blind index、精确 POST、无目录/日志 |
| WebCodecs/硬件不支持 | 无法自动压视频 | 能力前置检测、拒绝并给标准导出参数 |
| Tailwind v4 与目标微信 WebView 不兼容 | 样式缺失或交互不可用 | 组件生成前完成真实 WebView 门禁；不满足时统一固定 Tailwind v3.4 与兼容的 shadcn/ui 组件快照，不维护运行时双版本 |
| Base UI 与目标微信/辅助技术不兼容 | Drawer、Dialog、Select 或焦点行为失效 | 先用最小 Base UI 试验面验证并修复包装层；无法修复时新增 ADR 整体回退 Radix，不长期混用两个 base |
| 微信 SSE/自动播放差异 | 更新延迟/不能播 | 增量轮询、海报和点击播放降级 |
| CDN 域名依赖朋友 DNS | 证书/迁移受阻 | 明确责任、提前续期、MEDIA_BASE_URL 配置化 |
| 未成年人照片误发 | 隐私风险 | 默认口令禁下载、审核模式、隐藏/删除快速路径、学校授权流程 |
| CDN 盗刷 | 费用异常 | 短期 URL、不可枚举 key、配额/告警；不承诺绝对硬停 |
| OSS 回调/跨境不稳 | 上传状态丢失 | 不依赖回调，客户端完成 + API HEAD + 持久上传意图 |

## 12. 全项目完成定义

- 每项产品需求映射到实现和新鲜验证证据；
- 本地自动化、真实 OSS/CDN 冒烟和人工设备结果分开报告；
- 费用账单没有禁用项目；
- 图片/视频正文没有进入香港 HTTP/数据库/日志；
- OCR 图片没有离开上传设备，未确认号码不可搜索，号码明文不进入数据库/备份/日志；
- OCR 无候选不会产生任何确认标签/属性/无号码结论，确认号码可重复派生一致年级班级并正确过滤；
- 安全、备份恢复、删除和断线恢复均经过演练；
- 部署文档可由未参与开发者复现；
- 所有已知未验证项明确列出，不用推断升级为“已完成”。

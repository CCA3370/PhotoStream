# 测试与验收

状态：已批准的验证基线
更新日期：2026-08-27

## 1. 原则

- 从纯逻辑、数据库、浏览器到真实 OSS/CDN 逐层验证，越靠近真实云端，数据规模越小。
- 测试断言业务输出、状态变化和外部契约，不以覆盖率数字代替关键分支。
- 时间、随机数、签名时钟、网络错误和并发必须可控。
- 不启动未获授权的外部服务，不在真实 CDN 做并发压力测试。
- 所有完成结论记录命令、退出码、环境和关键结果；未运行的真实环境检查必须标为“未验证”。

## 2. 测试层级

| 层级 | 目标 | 外部资源 |
| --- | --- | --- |
| 单元 | 状态机、签名、校验、排序、限流、媒体规格 | 无 |
| 契约 | REST/SSE/OpenAPI 请求响应和错误 | 本地进程 |
| 数据库集成 | 事务、迁移、并发、outbox、任务恢复 | 本地 PostgreSQL |
| 浏览器组件 | Web Worker、IndexedDB、PWA、播放器、本地 OCR | 本地浏览器 |
| UI 组件/视觉 | Token、共享组件、响应式状态、键盘和自动无障碍 | 本地 Storybook/浏览器 |
| 端到端 | 登录到观众直播的完整流程 | 本地模拟 OSS/CDN 适配器 |
| 性能/压力 | 5,000 媒体、上传队列、500 SSE | 本地生成数据和媒体源 |
| 云端冒烟 | 预签名、私有回源、缓存、Range、账单边界 | 专用小型 OSS/CDN 测试对象 |
| 人工验收 | 微信、校园网络、真实设备与授权流程 | 经批准的测试相册 |

## 3. 单元测试

### 3.1 领域状态

- 相册合法/非法状态转换；
- 自动发布与审核发布分支；
- 照片 `preview_ready` 可发布但原图下载不可用；
- 视频海报或 MP4 不完整时不可发布；
- 发布序号并发分配无重复、无倒退；
- 隐藏、恢复、永久删除的权限和幂等；
- 口令改变递增 `accessVersion` 并使旧会话失效。
- OCR 候选不影响照片发布；只有 `confirmed` 且规则版本有效的号码可搜索。
- 号码规则改变后，合法标签升级版本、非法标签进入 `needs_review` 并退出搜索。
- 号码确认/修正自动派生年级班级；删除/规则变更同步清理或重算属性。
- OCR 无候选、失败或全拒绝保持 `pending`；只有人工无号码动作写 `no_number_confirmed`。

### 3.2 媒体校验

- JPEG/PNG/WebP 魔数、50MB、100MP 和动画拒绝；
- MP4/H.264/AAC、5 分钟、500MB、分辨率、帧率、码率和 fast-start 判断；
- object key 只使用服务端 ID，不接受路径穿越、Unicode 分隔符或原文件名；
- 照片变体规格、JPEG 退化和不放大规则；
- 视频输出预设与本地转码不可用时的稳定错误。
- 号码规则属性测试：不同总长度、前导零、任意起始位/宽度、重叠约束、多区间、模式并集、无解规则和规范化合并。
- 年级班级映射测试：任意位置/区间、输出选项、同维度冲突、缺失映射、标签映射版本和同号码确定性。

### 3.3 安全与签名

- 后台/访客会话创建、过期、吊销和角色矩阵；
- CSRF、Origin、Host 与 Cookie 属性；
- OSS V4 签名的路径、方法、头、时间和过期边界；
- CDN URL 主/备 key、时间戳、路径编码和过期；
- 临时鉴权参数不成为业务缓存 key；
- IP-HMAC 每日轮换后不可跨日关联。
- 号码 AEAD 加解密、相册作用域 HMAC blind index、密钥版本和精确匹配；数据库/错误不出现明文。

## 4. API 契约测试

- 所有路由严格拒绝未知字段和错误类型；
- 错误响应包含稳定错误码、中文信息、请求 ID 和可重试标志；
- 错误不泄露 SQL、Bucket、Endpoint、堆栈或密钥；
- 相同幂等键重复创建/完成/发布得到同一业务结果；
- 批量操作逐项返回结果并正确表达部分失败；
- 公共分页游标不可篡改、无遗漏/重复；
- 下载接口在三个独立开关下分别授权；
- SSE 使用单调 ID、心跳、断线补发和事件裁剪策略。
- 号码规则测试、候选提交/确认/拒绝/批量补录、权限和规则版本冲突；候选接口拒绝图片/blob/data URL。
- 号码搜索必须使用口令会话和 POST，拒绝公开相册、非法规则、模糊查询、过量请求与 URL 参数形式。
- 无号码确认/撤销/批量接口、确认号码互斥和迟到 OCR 候选；属性筛选要求年级且班级与同一标签匹配。

生成的 OpenAPI 文档必须与运行时验证共享同一 schema 来源，避免文档与实现漂移。

## 5. PostgreSQL 集成测试

- 从空库执行全部迁移，再回滚允许回滚的开发迁移；
- 唯一约束防止重复 object key、variant 和发布序号；
- 媒体发布与 outbox 同事务提交，模拟提交失败时两者均不出现；
- 多审核员并发发布同一媒体只成功一次；
- API 重启后从 `Last-Event-ID` 补发事件；
- 过期上传任务终止 multipart、清理孤立对象并可重试；
- 删除任务部分失败不会把媒体标记为彻底删除；
- 匿名明细 30 天清理、聚合保留；
- 号码密文/blind index 唯一性、多号码照片、规则重校验事务、相册结束 30 天候选清理和照片永久删除级联；
- 年级/班级派生字段、映射版本持久重算、重算期间过滤门禁，以及无号码复核结论的事务与级联删除；
- 备份生成、加密、上传、下载和隔离恢复演练。

## 6. 浏览器照片测试

样片覆盖横/竖屏、EXIF 旋转、透明 PNG、已有 WebP、100MP 边界、暗光、舞台灯光、运动和合影。

验证：

- Worker 不阻塞主线程并在每张处理后释放资源；
- 480/960/1920 尺寸、质量、格式和方向正确；
- 派生图无 EXIF/GPS；
- WebP 不支持时三个变体统一 JPEG；
- 480/960 先发布，1920/原图完成只触发更新；
- 刷新后合并服务端/IndexedDB 状态，不重传已完成对象；
- 移动端内存压力下队列降并发并给出错误。

使用独立脚本或浏览器测试记录每张样片各派生文件体积和视觉检查结果，不用主观“看起来差不多”替代记录。

## 7. 浏览器号码牌测试

使用至少 200 张已授权且位于 Git 外的本地评测照片，标注每个在 1920 派生图上人眼可无歧义读取的号码与四边形：至少 120 张清晰号码、40 张多人/倾斜/遮挡/暗光/运动模糊、40 张无有效号码但含背景数字。

验证：

- PaddleOCR.js Worker、OpenCV、ONNX Runtime 和模型全部从自有静态路径加载，无第三方 CDN/API；
- Chromium WebGPU 与 Safari/其他设备 WASM 降级；模型失败时照片仍上传且可手工补录；
- 全角数字/空白规范化，字母混淆不被静默替换；
- 一图多号码、重复框去重、最多 8 候选、规则过滤和版本变化；
- 上传者只操作自己照片，审核员/管理员操作全部；
- `suggested`、`rejected`、`needs_review` 均不能搜索，确认后无需重新发布即可搜索；
- 确认号码立即得到预期年级/班级；多号码照片分别派生，不跨号码组合属性；
- 历史照片没有自动补扫入口，但可单张/批量手工补录；
- OCR 无候选/失败/全拒绝都保持待复核；人工“无号码”、撤销、迟到候选、添加号码清除无号码和删除最后号码回待复核全部符合状态机；
- 搜索值不进入 URL、日志、统计、SSE、浏览器持久存储或 Referrer。

正式启用自动候选需达到：可读号码召回率 ≥90%；无有效号码照片平均错误候选 ≤1；单图候选中位数 ≤3；桌面 Chromium 暖机推理 p95 ≤3 秒；移动/Safari WASM p95 ≤8 秒；模型/运行时压缩总量 ≤35MB。任何 OCR 输出都不能自动成为确认号码、年级/班级或无号码结论。

固定记录模型/资源哈希、置信阈值、规则、浏览器、设备和评测集版本。门槛未达时，手工标签/搜索可通过，自动候选必须标为禁用或实验，不能降低人工确认门禁。

## 8. 浏览器视频测试

浏览器矩阵为当前 Chrome、Edge、Safari；转码能力以运行时 WebCodecs 检测为准。

样片覆盖：

- 合规 1080p/30fps/H.264/AAC fast-start，直接上传；
- `moov` 在尾部，仅重封装；
- 4K、60fps、高码率，转为 1080p/30fps/约 4Mbps；
- 720p 输出约 2Mbps；
- 静音、竖屏、极短片、接近 5 分钟和接近 500MB；
- 非 H.264、非 AAC、超限、损坏容器；
- 解码支持但编码不支持、转码中取消、页面切后台和磁盘不足。

输出验证包括容器 fast-start、codec、宽高、帧率、平均码率、时长、音画同步、方向、关键帧拖动与海报帧。

## 9. UI 组件、无障碍与视觉回归

本节描述工程建立后的必需验证层；Phase 0 没有 Storybook、Playwright 或可运行页面，当前结果必须标为 **Unverified**。

### 9.1 组件状态

为共享 Token、三个界面壳和实际使用的 shadcn/ui/Base UI 包装组件建立 Storybook 状态样例。每个交互组件至少覆盖：默认、悬停、键盘焦点、禁用、加载、错误、长中文、窄屏和减少动态效果。表单组件另外覆盖帮助文本、单字段错误、页面错误摘要、服务端错误和提交中重复操作。

关键业务组件必须覆盖：

- 公共相册口令、头部、分类、号码搜索、媒体卡片、新媒体提示、空状态和灯箱；
- 上传卡片的 `IngestStatus`、`PublicationStatus`、`BibTagStatus` 和 `BibReviewDecision` 四条独立状态轴，包括允许的并行组合；
- 队列暂停、离线、会话过期、权限变化、可重试/不可重试错误和部分成功；
- 审核选择、范围选择、批量操作、逐项失败、号码候选框、确认无号码和危险删除；
- 浅色工作台、公共相册浅/深色、默认强调色，以及近白、近黑、高饱和等无效候选强调色的安全回退。

组件样例使用生成的非人物占位媒体和虚构数据，不把真实未成年人照片、号码、口令或签名 URL 写入源码或截图基线。

### 9.2 自动无障碍

- Storybook 和关键 Playwright 页面状态运行 axe；WCAG A/AA 规则不得存在未解释的 violation。自动检查未覆盖项不能据此判定通过。
- 验证地标、标题顺序、控件名称/描述、字段错误关联、对比度、重复 ID、Dialog 语义和禁用/展开状态。
- 仅使用键盘完成登录、口令解锁、分类、号码搜索、灯箱、文件选择后的队列控制、审核选择和危险操作取消。
- 灯箱、抽屉和对话框验证焦点进入、约束、Escape、关闭恢复及嵌套浮层；虚拟化卸载原卡片时使用稳定的网格回退焦点，不把焦点留在已删除 DOM。
- 使用 VoiceOver + Safari 和 NVDA + Chrome/Edge 人工检查关键流程；上传进度与 SSE 更新不得逐百分比或逐心跳打断朗读。
- 触摸视口核心目标达到 `44×44 CSS px`；桌面高密度目标和间距至少满足 WCAG 2.2 AA 的目标尺寸要求。

### 9.3 响应式与视觉回归

固定使用 `360×800`、`390×844`、`768×1024`、`1280×800` 和 `1440×900` 五组视口生成确定性截图，覆盖公共相册、上传端和工作台。至少验证：

- 媒体列数、页面留白、侧栏/抽屉切换、上传摘要栏和底部安全区操作条符合 `docs/06-frontend-ux.md`；
- 中文标题放大到 200%、浏览器最小字号、长相册名和长错误文本不截断核心操作；
- 骨架与最终内容占位一致，没有因筛选栏、图片或客户端组件水合产生明显跳动；
- 深色公共相册只改变界面表面，媒体像素、海报和颜色管理不被 CSS filter 修改；
- 灯箱在横/竖图、视频、下载关闭、原图未完成和相邻预取失败时保持控制可见；
- 视觉基线只有在评审确认需求变化后更新，不能通过批量重录掩盖回归。

视觉截图只能证明固定夹具和视口；实际微信字体、系统控件、键盘弹出、安全区和手势仍需人工设备验收。

### 9.4 UI 技术门禁

- 在生成 shadcn/ui 组件前，用目标 iOS/Android 微信 WebView、Safari 和 Chromium 检查 Tailwind v4 所需 CSS 能力和一组纯 Token/布局样页。
- 全部支持环境通过时固定 Tailwind v4 当前安全小版本；任一承诺环境失败时统一固定 v3.4，并固定经验证兼容 v3.4 的 shadcn/ui 组件快照后重新验证，不混入 v4 专属语法或维护运行时双版本。
- 在 `apps/web` 初始化后运行 `pnpm dlx shadcn@latest info --json` 并保存结果。断言：base 为 Base UI、style 为 `base-nova`、RSC/TSX/CSS variables 开启、RTL 关闭、icon library 为 Lucide、base color 为 neutral、aliases 与解析路径落在 `apps/web/src`、自定义 registries 为空、没有第三方字体依赖；仓库不存在首版无消费者的 `packages/ui`。
- 只生成 Button、Field、InputGroup、Dialog、Drawer、Select、ToggleGroup、Sidebar 和 Toast 作为 Base UI 试验面；先在目标微信/浏览器、键盘和辅助技术上通过，再生成其他业务组件。Base UI 无法修复时必须新增 ADR 整体切换 Radix，不能在同一产品中逐页混用两个 base。
- iOS Safari/微信滚动页面后打开 Drawer，验证 overlay 完整覆盖视口、`body` 定位规则、滚动锁、软键盘、安全区、滑动关闭、焦点进入/恢复和嵌套浮层。
- 每个新组件先运行 `search` 和 `docs`，再用 `add --dry-run`/`--view`/`--diff` 审查文件、依赖、aliases 和全局 CSS；确认后才添加。禁止 `add --all`，没有用户明确批准不得 `--overwrite`、preset `apply` 或整批重装。
- 默认 `components.json` 不配置社区 registry。官方组件不足时，只读检查用户明确指定的 registry；安装前审查完整源码、依赖、CSS、环境变量、目标路径和 imports，GitHub 地址固定完整 commit SHA。
- 静态规则检查覆盖：`InputGroupInput/InputGroupTextarea` 与 `InputGroupAddon`、Item/Group 配对、完整 Card 结构、`TabsList`、`AvatarFallback`、Base `render`/`nativeButton`、Button `Spinner`/`data-icon`/disabled、Lucide 对象图标，以及 `gap-*`、`size-*`、`truncate`、`cn()` 和语义颜色约束。
- Base UI 项目只存在 shadcn `Toast`，不同时安装 Sonner；页面级错误、字段错误和危险确认不依赖 Toast。
- 公共相册构建分析确认工作台、Storybook、OCR、转码和未使用 shadcn/ui 组件不在初始客户端图。
- 检查 Server/Client 边界：Client Component 不得为异步函数，跨边界属性均可序列化，浏览器专用库不进入服务端图；关键路由没有水合错误或因导航 hooks 缺少 Suspense 导致整页 CSR。
- 公共媒体网络记录只能出现签名 CDN URL，不得出现 `/_next/image`、香港媒体代理或 Next.js 主动抓取；`next/image` 使用 `unoptimized` 时仍验证 `sizes`、占位尺寸和懒加载。
- Next.js 加载、段级/全局错误、未找到、未登录和无权限页面使用统一状态组件；公共相册未知/无权仍保持同一外部表现。
- Base UI Dialog、Select、Popover、Drawer、Sidebar 和 Tooltip 在目标浏览器及辅助技术组合中逐项验收；发现关键缺陷时先修复包装层，无法修复才触发 ADR-010 重审。

## 10. 端到端场景

1. 管理员创建默认口令/禁下载/审核相册。
2. 创建上传者和审核员，验证首次改密与角色限制。
3. 上传者选择分类并上传多张照片；观众在审核前不可见。
4. 审核员发布，观众收到 SSE；离开顶部时只出现新影像提示。
5. 1920/原图稍后完成，排序不变、下载能力按开关更新。
6. 启用结构化号码规则和年级/班级映射，上传照片不等待 OCR；确认候选后自动出现正确属性，口令观众可精确号码或按年级/班级找到照片。
7. 多号码照片中，用年级+班级筛选只能由同一号码满足，不能交叉拼接两个人的属性。
8. 对 OCR 无候选照片验证仍为待复核；人工确认无号码后普通流可见但号码/属性筛选不出现，添加号码会撤销无号码。
9. 修改号码/属性规则，失效标签退出搜索、属性持久重算；旧照片只通过审核员手工补录。
10. 上传高码率 H.264 MP4，本地转码、分片上传、审核和发布。
11. 视频进入视口 75% 后静音播放，同一时间没有第二条并播；弱网/省流量只显示海报。
12. 改相册口令，原观众会话失效；改为公开相册时号码搜索关闭。
13. 分别开启普通图、原图和视频下载并验证 5 分钟地址。
14. 隐藏媒体后从增量流移除；永久删除完成 OSS 删除、号码/属性/复核结论删除与 CDN 刷新。
15. API/数据库重启，上传、号码重校验/属性重算任务和 SSE 按持久状态恢复。
16. 上传中会话过期：停止新签名/完成请求、保留 IndexedDB 队列，重新登录后查询服务端对象/分片并只续传缺失部分。
17. 操作中角色或相册权限被撤销：界面撤销对应编辑和批量动作、保留本地文件但不绕过服务端，并给出明确人工下一步。
18. 在手机/平板/桌面分别完成三类界面壳导航；无权入口不可见，直接访问仍由服务端拒绝，关闭对话框和灯箱后焦点返回合理位置。

# 费用控制

状态：已批准的费用边界
更新日期：2026-08-30

## 1. 费用原则

阿里云费用允许包含 OSS 与 CDN 的基础、不可避免项目；任何可选处理、计算、OCR/AI、日志或安全产品默认禁止启用。

价格、免费额度和资源包规则可能变化。上线前必须以阿里云控制台和官方计费页面重新确认，不在代码或文档中写死单价。

## 2. 允许的计费项

| 产品 | 允许项目 | 产生原因 |
| --- | --- | --- |
| OSS | 标准存储容量 | 长期保存照片、派生图、静态/OCR 模型资源和备份 |
| OSS | PUT 类请求 | 普通上传、multipart 初始化/分片/完成/终止、删除 |
| OSS | GET/HEAD 类请求 | CDN 回源、对象完成校验、恢复备份 |
| OSS | CDN 回源流量 | CDN 节点未命中时从 OSS 获取对象 |
| CDN | 中国内地下行流量 | 观众浏览和下载 |
| CDN | 静态 HTTPS 请求 | HTTPS 媒体与静态资源请求；免费额度外可能计费 |

使用两个 OSS Bucket 不会引入新的产品种类，但各自存储和请求均计入上述基础项目。

## 3. 禁止项目

- 函数计算 CU/公网流量；
- OSS 图片处理、高级压缩、IMM、传输加速、跨区域复制、KMS、数据索引；
- 阿里云或第三方云端媒体处理；
- CDN 图片处理、实时日志、QUIC、远程鉴权、WAF；
- 阿里云或其他第三方托管 OCR、视觉识别、模型推理和训练服务；
- DCDN、ESA、RDS、Tair、消息队列、日志服务；
- 任何“先开通再观察是否收费”的可选功能。

新增阿里云产品或控制台开关前，必须更新本文件并获得用户明确批准。

## 4. 基础成本结构

### 4.1 照片

每张完整照片通常产生四个长期对象：480、960、1920 WebP 和原图。

- 三个派生图各一次 PUT；
- 原图小于等于 16MiB 时一次 PUT；
- 原图大于 16MiB 时产生初始化、每个 8MiB part 和完成请求；
- API 完成校验产生 HEAD 请求；
- 观众网格只请求 480/960，灯箱请求 1920，原图只在明确下载时请求。

小图先发布增加少量 OSS 存储，但显著避免浏览列表下行原图，是主要节流策略。

### 4.2 静态资源与备份

- 每次前端 release 上传一组哈希静态文件，长缓存后重复访问不回源。
- PaddleOCR.js Worker、OpenCV.js、ONNX Runtime WASM 和 PP-OCR 模型按模型版本上传；只由启用识别的内部页面首次懒加载，压缩总量预算不超过 35MB并缓存一年。
- 数据库备份每日一个密文对象，按 14 日备份和 8 周备份保留。
- Service Worker 与动态 HTML 由香港主机提供，不计入阿里云 CDN。

号码识别不新增照片派生对象。候选、密文、blind index、置信度、框坐标、年级/班级派生属性和无号码复核结论只增加少量香港 PostgreSQL 数据与加密备份体积；属性规则变化只重算元数据，不重新下载/OCR 图片。

## 5. CDN 流量优化

1. 规整网格按视口选择 480/960，不自动下载 1920 或原图。
2. 图片懒加载、虚拟化；灯箱只预取相邻一张，省流量模式不预取。
3. 不可变 object key 与一年边缘缓存，鉴权参数不进入 cache key。
4. 公共静态资源使用哈希文件名和一年浏览器/CDN 缓存。
5. 下载默认关闭；原图地址只在用户明确点击时签发。
6. API/SSE 不走 CDN，不把动态查询参数制造为新静态缓存对象。
7. OCR 模型只在内部识别页面按版本加载一次；观众端和未启用相册不请求模型，禁止第三方 CDN 回退。

## 6. 存储控制

用户选择媒体全部使用标准存储并长期保留，因此不配置低频、归档或自动媒体删除。控制手段改为：

- 每场默认 5,000 张照片硬配额；
- 创建上传意图前检查已完成对象与在途声明大小；
- 取消/过期上传清理已上传孤立对象和 multipart；
- 管理后台显示每场原图、派生图、静态资源和备份的逻辑字节数；
- 相册结束 30 天后清理未确认、已拒绝和未解决号码候选；确认标签随相册保留；
- 永久删除按对象实际完成并可重试，避免“数据库删了、OSS 还在”。

## 7. 访问与滥用控制

- 默认口令相册和短期 URL，object key 不可枚举。
- API 限制单会话媒体分页、下载地址签发频率和并发上传数。
- 号码搜索只用于口令相册，每个会话/IP-HMAC 每 10 分钟最多 30 次，不提供号码目录或模糊枚举。
- CDN URL 鉴权能降低长期盗链，但鉴权失败请求仍可能产生 HTTPS 请求与少量流量费用。
- 相册公开或开启下载时，后台必须展示费用与二次传播提示。
- 学校应在阿里云费用中心设置余额/账单提醒，并定期查看 CDN 域名流量趋势；不得为了精确统计启用付费实时日志。

在确认相关查询 API 不单独收费后，可由香港主机使用只读 RAM 权限周期读取 CDN/OSS 用量并在后台提示。该能力不是首版上线前置条件，也不能宣称为实时硬停。

## 8. 无法保证的硬上限

标准 CDN 不具备“达到某金额立即停止且绝不超额”的精确账单硬闸。账单存在延迟，盗刷请求即使被鉴权拒绝也可能产生费用。

首版不自动停 CDN，因为错误阈值可能让学校活动突然不可用。若以后需要硬停，必须单独设计：使用量数据延迟、停服阈值、管理员确认、恢复步骤和活动期间例外；不得在未讨论的情况下加入。

## 9. 费用验收

上线前和首场活动后分别导出账单明细，确认：

- 没有函数计算、图片/OCR 处理、视觉识别、云端媒体处理、DCDN/ESA、实时日志、KMS 等项目；
- OSS 只出现标准存储、基础请求和 CDN 回源相关项目；
- CDN 只出现基础下行与静态 HTTPS 请求；
- 相同媒体的不同临时签名命中同一缓存对象；
- 相册页面没有自动请求照片原图；
- 观众端不加载 OCR 运行时；内部模型第二次加载命中长缓存且没有第三方 OCR/模型请求；
- 实际平均照片下行体积与本地样片预算一致。
